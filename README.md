## ✨ المميزات الرئيسية (Key Features)

- **🏛️ هيدر ملكي شفاف وشريط تنقل جذاب**: شريط علوي ملفت باللون الأخضر الزمردي والذهب يتضمن روابط (اتصل بنا، من نحن، شروط الاستخدام، سياسة الخصوصية، المدونة، والمتجر).
- **💎 الهوية البصرية**: ألوان الذهب الملكي (`#D4AF37`)، الأخضر الزمردي الماسي (`#059669`)، والأسود الملكي (`#18181B`) على خلفية عاجية مريحة للعين.
- **🏡 عقارات النخبة**: استعراض الفلل والقصور الفاخرة بالرياض ودبي مع تفاصيل المساحة والغرف ورخص التوثيق العقاري.
- **🧮 حاسبة التمويل العقاري الذكية**: حساب القسط الشهري، الدفعة الأولى، ونسبة المرابحة برسم بياني تفاعلي.
- **🤖 المستشار الملكي الذكي (AI Advisor)**: مدعوم بنموذج `@google/genai` (Gemini 3.8 Flash) عبر Express API للإجابة الاستشارية الفورية.
- **🎮 متجر المنتجات الرقمية**: ألعاب الجمعات، مخططات 2026 الهندسية (DWG/PDF)، وقوالب كانفا (Canva Kits) بالتنزيل المباشر.
- **🛍️ سلة ومفضلة تفاعلية**: إدارة المشتريات، تطبيق كود الخصم (`HANAN10`)، واستخراج الفاتورة الرسمية المعتمدة.
- **📜 الامتثال القانوني وAdSense**: صفحات رسمية مكتملة (سياسة الخصوصية، الشروط، من نحن، اتصل بنا، وإثبات ملكية الدومين) ومساحات إعلانية معتمدة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, TypeScript, Vite 8, Tailwind CSS v4, Motion, Lucide React Icons.
- **Backend & AI**: Node.js, Express, `@google/genai` SDK (`gemini-3.8-flash`).
- **Typography**: Google Fonts (Cairo, Amiri, Tajawal).

---

## 🚀 تشغيل المشروع محلياً (Run Locally)

```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. إعداد مفتاح بيئة جيميناي في ملف .env
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"

# 3. تشغيل الخادم والتطوير
npm run dev
```
